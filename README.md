💼 Resume Screening AI (NLP)
📌 Overview

Resume Screening AI is an NLP-based system that automatically classifies and ranks resumes based on their similarity to a given job description.

It helps recruiters efficiently shortlist candidates using Machine Learning and text similarity techniques.

🚀 Features

Resume text preprocessing

TF-IDF vectorization

Cosine similarity-based ranking

Job category prediction (ML model)

Match percentage generation

Streamlit web application

Download shortlisted candidates (CSV)

🛠️ Tech Stack

Python

Pandas & NumPy

NLTK

Scikit-learn

TF-IDF

Cosine Similarity

Streamlit

⚙️ Workflow

Load and clean resume data

Convert text into TF-IDF vectors

Train classification model

Calculate similarity with job description

Rank resumes based on match %

Display results in web app

📊 Model Performance

Multi-class classification

~74% accuracy (improved dataset)

📂 Dataset

resume_dataset.csv

Resume text + job categories
